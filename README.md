# Invitaciones Digitales

Sistema de invitaciones digitales para eventos. Admin centralizado, pensado para escalar a multi-organizador más adelante.

## Setup

1. `npm install`
2. Crear proyecto en [supabase.com](https://supabase.com), correr `supabase/schema.sql` en el SQL editor
3. Copiar `.env.example` a `.env.local` y completar con las credenciales de Supabase
4. `npm run dev`
